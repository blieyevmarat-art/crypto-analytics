📊 Crypto Analytics: Анализ волатильности BTC/USDT

📝 Описание проекта
Pet-проект, демонстрирующий полный цикл работы с данными (ETL) и аналитику криптовалютного рынка.
Цель: проанализировать исторические данные пары BTC/USDT, выявить волатильные периоды и проверить бизнес-гипотезы через A/B-тест.

🛠 Стек технологий

• Язык: Python 3.12

• База данных: PostgreSQL

• Библиотеки: Pandas, SQLAlchemy, Plotly, Matplotlib, SciPy

• BI-инструмент: Power BI (дашборд в разработке)

• Среда: Jupyter Notebook

• Инструменты: Git, Linux (Ubuntu)

🚀 Что было сделано (Этапы работы)
1. ETL (Извлечение, Трансформация, Загрузка):
◦ Написан скрипт (src/download_data.py) для скачивания исторических данных (731 день) через API Yahoo Finance (yfinance).
◦ Данные очищены, приведены к нужным типам и загружены в PostgreSQL (src/load_to_postgres.py).
2. SQL-аналитика:
◦ Написано более 10 запросов разного уровня сложности (от базовых агрегаций до оконных функций и CTE). Все запросы сохранены в sql/queries.sql.
3. Исследовательский анализ (EDA):
◦ В ноутбуке notebooks/01_exploration.ipynb построен интерактивный свечной график (Candlestick) с наложением скользящих средних (MA_7, MA_30) с помощью Plotly.
4. Статистика и гипотезы:
◦ Проведен симулированный A/B-тест (конверсия красной vs зеленой кнопки). Рассчитан P-value, доказана статистическая значимость.
5. Сегментация:
◦ Проведен RFM-анализ для сегментации торговых дней по уровню волатильности и объемам торгов.
